# Invoicely — Free Invoice Generator

A premium, free invoice generator built with React. Create professional invoices and download them as PDF — no signup required.

## Features

- Live invoice preview as you type
- PDF download (powered by jsPDF)
- Multiple currencies (USD, INR, GBP, EUR, AUD, CAD)
- Line items with auto-calculated totals
- Discount and tax/GST support
- Upload your business logo
- Fully responsive design
- No data sent to any server — everything runs in your browser

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- Vite
- jsPDF (CDN)
- Lucide React icons
- Google Fonts (Inter + Instrument Serif)
